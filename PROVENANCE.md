# Provenance

FleetForge application source, fixtures and procedural warehouse geometry were newly authored in this repository for this hackathon build on 2026-10-25, with coding-agent assistance. No JootaFly source, scans, Zellerfeld templates, licensed shoe geometry or private data were copied into the application. The existing footwear workshop informed the idea of a small, visible manufacturing environment.

The greedy controller is a deliberately seeded demonstration fault. The cooperative controller is a local reference implementation developed with coding-agent assistance. Neither is represented as output from the Gemini Managed Agents service. Generated managed candidates retain `gemini-managed` provenance only when returned by the actual configured service.

The original ten-option planning effort and the supplied event guides informed the selected architecture. Research notes in `docs/` describe proposals; current implementation and validation status are recorded in `docs/BUILD.md` and `docs/STATUS.md`. The application uses original boxes, racks, floor markings, docks and robot geometry rather than external 3D assets.

Runtime dependencies retain their own licenses; pinned versions are in `package-lock.json`. The application is offered under the MIT license in `LICENSE`. No permission is implied for unrelated pre-existing project files outside this repository.
